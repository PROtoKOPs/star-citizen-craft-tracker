Изображения в этой папке загружены с Star Citizen Wiki (https://starcitizen.tools)
для локального отображения в fan-made трекере Wikelo Tracker.

- contracts/ — изображения итоговых предметов из таблицы контрактов Wikelo.
- resources/ — миниатюры ресурсов и компонентов.
- rewards/ — миниатюры наград.

Файлы сохранены локально, чтобы приложение работало без интернета.
Права на игру и материалы принадлежат Cloud Imperium Games и соответствующим
правообладателям. Star Citizen является товарным знаком Cloud Imperium Games.
