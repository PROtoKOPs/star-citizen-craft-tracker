# Star Citizen Craft Tracker

Локальный трекер для Star Citizen: контракты Викело, склад с качеством, Item Fabricator и лут-гид. Приложение работает офлайн, не требует установки и сборки — достаточно открыть `index.html` в браузере.

[Последний релиз](https://github.com/PROtoKOPs/star-citizen-craft-tracker/releases/latest) · [Репозиторий](https://github.com/PROtoKOPs/star-citizen-craft-tracker)

## Возможности

- **Контракты Викело.** 65 контрактов с чек-листами, наградами, репутацией и прогрессом.
- **Склад с качеством.** 125 ресурсов, партии Q0–Q1000, свободный остаток и внесённые ресурсы. Партии возвращаются на склад с исходным качеством.
- **Item Fabricator.** 1 613 чертежей: материалы, миссии, характеристики, сравнение специальных версий с обычными и минимальные цены за aUEC.
- **Прогноз крафта.** Предварительное качество предмета и модификаторы характеристик по вложенным материалам.
- **Свои фото материалов.** Загрузка из файла или буфера обмена, хранение в браузере.
- **Лут-гид.** 23 локации в Stanton, Pyro и Nyx с фильтрами и маршрутами.
- **Данные и обновления.** Импорт/экспорт JSON и CSV, автосохранение и проверка новых версий через GitHub.

## Быстрый старт

1. Скачайте ZIP из [последнего релиза](https://github.com/PROtoKOPs/star-citizen-craft-tracker/releases/latest) или клонируйте репозиторий.
2. Распакуйте архив, если скачали ZIP, и откройте `index.html`.
3. В «Контрактах» отметьте найденное, а в «Моих ресурсах» добавьте партии с качеством.
4. Для резервной копии используйте «Экспорт»; «Импорт» загружает JSON обратно.

Сборка, Node.js и интернет не нужны. Все данные хранятся в `localStorage` браузера.

## Данные

- Контракты и награды: [Star Citizen Wiki](https://starcitizen.tools/Wikelo), снимок от 28.10.2026 (Alpha 4.8.2).
- Чертежи: [Jokers Gambit](https://jokersgambit.org/blueprints) и Star Citizen Wiki API (4.10.2).
- Характеристики, качество и цены: Star Citizen Wiki API и UEX (4.10.2).
- Данные — снимки на конец октября 2026. После патчей игры их нужно обновлять вручную.

## Структура

```text
index.html            — разметка
styles.css            — оформление
app.js                — логика и состояние
data.js               — контракты Викело
fabricator-data.js    — чертежи Item Fabricator
comparison-data.js    — сравнение версий и цены
quality-data.js       — модификаторы качества
loot-data.js          — места для лута
details.js            — описания ресурсов
version.json          — версия для проверки обновлений
assets/               — изображения
```

## Обновления

При запуске приложение сравнивает свою версию с `version.json` в ветке `main`. Если доступна новая версия, внизу появляется баннер со ссылкой на релиз. Проверить вручную можно в «О приложении → Проверить обновления». Без интернета проверка пропускается.

## Ограничения

- Прогноз качества крафта — локальная оценка, а не игровой расчёт.
- Данные могут устаревать после обновлений Star Citizen.
- Свои фото материалов хранятся в `localStorage`; при большом количестве снимков возможен лимит браузера.
