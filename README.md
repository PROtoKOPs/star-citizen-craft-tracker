# Star Citizen Craft Tracker

Офлайн-трекер для Star Citizen: контракты Викело, личный склад, Item Fabricator и лут. Работает без установки и интернета — откройте `index.html` в браузере.

Репозиторий: [github.com/PROtoKOPs/star-citizen-craft-tracker](https://github.com/PROtoKOPs/star-citizen-craft-tracker) · Релизы: [releases/latest](https://github.com/PROtoKOPs/star-citizen-craft-tracker/releases/latest)

## Что умеет

- **65 контрактов Викело** — чек-листы, награды, репутация и прогресс.
- **Склад с качеством** — партии ресурсов Q0–Q1000 (Q500 — базовое), внесение в контракты и крафт, возврат с сохранением качества.
- **Прогноз крафта** — итоговое качество предмета по вложенным материалам и модификаторы характеристик.
- **Свои фото материалов** — загрузка из файла или буфера обмена, возврат оригинала.
- **125 ресурсов** в общей вкладке: Викело + все рецепты фабрикатора.
- **1 613 чертежей Item Fabricator** — материалы, миссии, характеристики и цены за aUEC.
- **Лут-гид** — 23 проверенных места в Stanton, Pyro и Nyx.
- **Импорт/экспорт JSON и CSV**, автосохранение в браузере.
- **Проверка обновлений** — при запуске сверяет версию с `version.json` на GitHub и предлагает скачать новый релиз. Без интернета проверка молча пропускается.

## Быстрый старт

1. Откройте `index.html`.
2. В «Контрактах» отметьте найденное или добавьте ресурсы на склад во вкладке «Мои ресурсы» (качество — в «Партии качества»).
3. Кнопка «Внести» переносит ресурс со склада в контракт или чертёж, «Вернуть» возвращает его.
4. В чертеже смотрите «Качество крафта», в контракте — «Чем отличается награда».
5. Прогресс сохраняется автоматически; для резервной копии используйте «Экспорт».

## Обновление

Приложение сравнивает локальную версию с `version.json` из ветки `main`. Если вышла новая версия, внизу появится баннер со ссылкой на релиз. Ручная проверка — «О приложении → Проверить обновления».

Чтобы выпустить новую версию: поднимите `APP_VERSION` в `app.js` и `"version"` в `version.json`, запушьте в `main` и создайте релиз с ZIP-архивом.

## Структура

```
index.html            — разметка
styles.css            — оформление
app.js                — логика и состояние
data.js               — контракты Викело
fabricator-data.js    — чертежи Item Fabricator
comparison-data.js    — сравнение вариантов и цены
quality-data.js       — модификаторы качества крафта
loot-data.js          — места для лута
details.js            — описания ресурсов
version.json          — версия для проверки обновлений
assets/               — изображения
```

## Источники данных

- Контракты и награды: [Star Citizen Wiki](https://starcitizen.tools/Wikelo).
- Чертежи: [Jokers Gambit](https://jokersgambit.org/blueprints) и Star Citizen Wiki API (4.10.2-LIVE).
- Характеристики, качество и цены: Star Citizen Wiki API, UEX.
- Данные — снимки на конец октября 2026; после патчей сверяйтесь с игрой.
